# ROBOCALC — платформа подбора роботизированных решений

Веб-платформа экспресс-предынвестиционной оценки роботизации объекта: пользователь
выбирает отрасль и тип объекта (склад / аэропорт / медучреждение), платформа
подбирает подходящие роботизированные решения из каталога, считает экономику
(CAPEX/OPEX/TCO/ROI/срок окупаемости) по нескольким сценариям финансирования и
показывает работу роботов на 2D-плане объекта — чтобы подтвердить расчётную
производительность до реального внедрения.

Решение подготовлено для кейса Федерального центра беспилотных авиационных
систем «Разработка платформы подбора роботизированных решений с расчётом
экономического эффекта и визуализацией работы роботов на объекте» (2026).

## Быстрый старт

Единственная предпосылка — установленный [Docker Desktop](https://www.docker.com/products/docker-desktop/).

```bash
git clone https://github.com/TasFoster/LCT.git
cd LCT
```

**Windows, без консоли:** дважды кликните `Запустить проект.bat` в корне репозитория —
скрипт сам поднимет оба сервиса и откроет браузер на нужной странице. Первый запуск
занимает 5–10 минут (сборка образов), следующие — около минуты. Остановить —
`Остановить проект.bat`.

**Через консоль (любая ОС):**

```bash
docker compose up --build
```

Фронтенд — http://localhost:5173, бэкенд (OpenAPI-схема) — http://localhost:8000/openapi.json.

Подробная пошаговая инструкция «от установки Docker до просчитанного проекта»,
без предположений о техническом опыте — **[«ИНСТРУКЦИЯ (для Александры).md»](./ИНСТРУКЦИЯ%20(для%20Александры).md)**.

### Локальный запуск без Docker (для разработки)

```bash
# backend
cd Project/backend
pip install -r requirements.txt
uvicorn api.main:app --reload --port 8000

# frontend, в отдельном терминале
cd Project/frontend
npm install
npm run dev
```

## Структура репозитория

```
Project/backend/    контракты данных (pydantic), подбор, симуляция, экономика, API (FastAPI), SQLite
Project/frontend/   визард из 8 шагов, 2D-редактор плана (React 19 + TypeScript + Vite)
Датасет/            каталог организатора (223 позиции) и демо-параметры объектов
Документация/       проектная документация по зонам ответственности
```

## Стек

Backend: Python, FastAPI, Pydantic, SQLite.
Frontend: React 19, TypeScript, Vite, react-konva (2D-редактор плана).
Инфраструктура: Docker Compose (backend + nginx для фронтенда).
