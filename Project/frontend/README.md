# Фронтенд

React 19 + TypeScript + Vite. Все экраны из [карты экранов](../../Документация/Фронтенд%20и%20визард/architecture/pages.md)
свёрстаны и связаны навигацией. Данные — моки, формы работают локально,
2D-редактор, 3D и симуляция — заглушки с готовым каркасом экрана.

Рядом, в [`editor2d/`](editor2d/), живёт 2D-редактор сцены Алексея — пока
независимое Vite-приложение (свой `package.json`, порт 5173, не запускать
одновременно с этим). Как он встраивается в шаг 7 и какие данные получает —
[`editor-and-api.md`](../../Документация/Фронтенд%20и%20визард/editor-and-api.md).

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # tsc -b && vite build
npm run lint
```

Роль переключается селектом «Роль» в шапке или параметром адреса
`?as=user` / `?as=admin` (заглушка вместо авторизации, роль живёт до
закрытия вкладки). На странице входа e-mail со словом `admin` входит
администратором.

## Что готово, что заглушка

| Часть | Состояние |
|---|---|
| Все маршруты, гарды по ролям, 403/404 | готово |
| Дизайн-система: токены, светлая и тёмная тема, UI-кит | готово |
| Главная, каталог (карточки/таблица, фильтры), карточка решения | готово, данные — мок |
| Вход, регистрация (с переносом демо-расчёта), восстановление пароля | вёрстка и валидация; авторизация — заглушка |
| Мои проекты: поиск, фильтры, сортировка, копия, архив | готово, данные — мок |
| Новый проект, обзор проекта, версии, профиль | готово, сохранение — заглушка |
| Визард, шаги 1–6 и 8 | готово: валидация, подсказки, долгие расчёты со статусом |
| Шаг 7 «Визуализация» | **заглушка**: каркас (инструменты, роботы, зоны, KPI, управление симуляцией) есть, редактор и 3D встраиваются в отмеченные области |
| Итоговый дашборд: KPI, сравнение, график денежного потока, структура затрат, чувствительность, допущения | готово на расчёте-заглушке |
| Отчёт для печати | готово; PDF — через печать браузера |
| Экспорт PDF/Excel, импорт CSV/Excel | заглушки с объяснением |
| Админка: сводка, каталог, карточка позиции, правила, справочники, допущения, пользователи | готово, сохранение — заглушка |
| Демо-режим гостя (`/demo`) | готово: шаги 1–6, один сценарий, 7–8 закрыты с объяснением |

Экраны на моковых данных помечены жёлтой плашкой «Демонстрационные данные».

## Где лежат заглушки — что заменить при подключении API

| Файл | Что это | На что заменить |
|---|---|---|
| `shared/mock/*` | каталог, проекты, результаты подбора, справочники, правила, пользователи | запросы через `@tanstack/react-query` |
| `features/wizard/mockEconomics.ts` | упрощённый расчёт экономики на фронте | econWrapper (`EconomicsResult` из API) |
| `features/wizard/useMockCalc.ts` | имитация долгого расчёта | статус задачи с бэкенда |
| `features/wizard/store.ts` | черновик визарда в sessionStorage | автосохранение на бэкенд (у гостя остаётся sessionStorage) |
| `features/auth/session.ts` | роль без авторизации | реальная сессия |
| `pages/wizard/steps/StepTopology.tsx` | каркас шага 7 | editor2d / viewer3d / проигрыватель `SimulationTimeline` |
| `features/projectApi/mockServer.ts` | мок сервера проектов: версии записи, 409/422, проверки плана | реальные вызовы через `shared/api/endpoints/` |
| `features/planEditor/PlanEditorStub.tsx` | временный редактор плана с интерфейсом `PlanEditorProps` | компонент из `editor2d` |

## Структура

```
src/
  app/            App.tsx (маршруты), RootLayout, guards
  pages/
    public/       главная, каталог, карточка решения
    auth/         вход, регистрация, восстановление пароля
    projects/     список, новый, обзор, версии, дашборд, отчёт, профиль
    wizard/       WizardPage (степпер, переходы), WizardFooter, GuestLock, steps/ — 8 шагов
    admin/        AdminLayout и страницы админки
    errors/       403, 404
    wireframes/   исходные вайрфреймы
  widgets/        шапка, полоса проекта, таблица сценариев, график, чувствительность, статус расчёта
  features/
    auth/         сессия (заглушка)
    wizard/       черновик, описание полей формы, прогресс шагов, расчёт-заглушка
  shared/
    config/       routes.ts — все маршруты и шаги визарда
    api/          endpoints/ — описание всех ручек api-routes.md, projectState.ts — состояние записи проекта
    dictionaries/ склейка categories.json + form_options.json из backend/contracts
    types/        contracts.ts — типы по backend/contracts/*.md
    mock/         моковые данные
    ui/           UI-кит: Button, поля форм, Card, Chip, Stat, Alert, EmptyState, Stub…
    lib/          форматирование чисел, денег, дат, склонения
    styles/       tokens.css (тема), base.css, components.css
```

## Договорённости

- Маршруты — только из `shared/config/routes.ts`.
- Шаг визарда адресуется слагом (`/wizard/params`), не номером.
- Форма параметров строится из описания полей (`features/wizard/paramsSchema.ts`):
  новый тип объекта — новое описание, не новая вёрстка.
- Цвета — только через токены из `tokens.css`; тёмная тема переопределяет
  значения, компоненты о теме не знают.
- Рабочее разрешение — от 1366×768: липкие колонки ограничены по высоте,
  кнопки действий не уходят под нижнюю панель.
- Интерфейс на русском; числа — с пробелами-разрядами, у каждого числа единица.
- Лучший сценарий выбирается по выгоде за горизонт (= минимальный TCO), а не
  по окупаемости: иначе всегда побеждает RaaS с почти нулевым CAPEX.
