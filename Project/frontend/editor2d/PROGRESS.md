# Журнал работ — editor2d

Правило: один пункт за раз → сразу проверка → запись сюда → следующий пункт.

Автотесты: `npm test` (Vitest) — прогонять после каждой правки логики; новые проверки логики добавлять в `*.test.ts` рядом с кодом.

Проверка: перед тестом в браузере убедиться, что Vite отдаёт новую версию файла (`fetch('/src/...?t=')`).
На Windows Vite может пропустить вторую быструю запись в тот же файл — тогда обновить время файла.
JSX-комментарии Vite вырезает — свежесть проверять по коду или по состоянию страницы, а не по комментарию.
Инструменты правки и команды превращают запись `\uXXXX` в настоящие символы — такие последовательности собирать в Python через chr(92) и проверять байты.
