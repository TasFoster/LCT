# enums.py

Общие перечисления, используются во всех остальных контрактах. Новое значение
enum = новый вариант данных без изменения кода, который эти enum использует.

## ObjectType
| Значение | Описание |
|---|---|
| `warehouse` | Склад |
| `airport` | Аэропорт |
| `medical` | Медицинское учреждение |

## AvailabilityStatus
| Значение | Описание |
|---|---|
| `available` | Доступно к поставке |
| `limited` | Ограниченная доступность |
| `discontinued` | Снято с производства |
| `upcoming` | Ожидается на рынке |

## AcquisitionModel
| Значение | Описание |
|---|---|
| `purchase` | Покупка |
| `leasing` | Лизинг |
| `raas` | Robot as a Service (аренда/услуга) |

## NavigationType
| Значение | Описание |
|---|---|

| `wire_guided` | Индукционный провод |
| `other` | Другое |

## CompatibilityVerdict
| Значение | Описание |
|---|---|

| `needs_review` | Недостаточно данных, требует проверки вручную |

|---|---|
