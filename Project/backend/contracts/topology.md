# topology.py — контракт 6: Scene

Граница: **Алексей (editor2d, `Project/frontend/editor2d/`) → Артём/Стас (matching), Стас (simulation), Владимиров (хранение)**.

Файл называется `topology.py` по историческим причинам (контракт 6 в `contracts/__init__.py`),
но с этой версии он — pydantic-зеркало реального контракта сцены, который ведёт Алексей:
**[`../../scene.md`](../../scene.md)** — там же таблицы полей, правила координат/единиц и
список проверок. Не дублируем таблицы здесь: при изменении `scene.md` синхронизируй
`topology.py` (этот модуль) вручную, а этот файл достаточно обновить одной строкой в
таблице ниже.

## Чего здесь нет, но есть в `scene.md`

- Проверки (`errors`/`warnings` из раздела «Проверки») — их выполняет `frontend/editor2d/src/scene/validate.ts`
  на стороне редактора перед отдачей; бэкенд получает уже проверенную сцену и полагается на
  структурную валидацию pydantic (обязательность полей, `min_length` у списков вершин, `ge=1` у `slots` и т.п.),
  а не переигрывает геометрические проверки (самопересечение полигона и т.д.).
- Апгрейд файлов v1.0/v1.1 без `walls` (`withDefaults` в редакторе) — на бэкенд всегда приходит
  уже нормализованная сцена текущей версии.
